# 官方更新与插件兼容性台账

## 目标与口径

本台账的目标是增强 AG99、保持对 AstrBot 生态插件的兼容，并在不破坏本地架构的前提下跟随官方版本演进。官方提交是**能力和兼容性参考**，不是要求逐字复制的源码目标。

- 优先吸收会影响插件可用性的公开契约：版本范围、插件元数据、API/路由、事件与消息组件、配置结构和 Dashboard 接口。
- 对本地已有等效实现记为 `equivalent`，对架构不同但行为已适配的实现记为 `adapted`；不把 Git 提交是否同一个对象当成完成标准。
- 保留 AG99 自己的 Prompt、Personal、Core、Interaction、消息投递和前端分区设计。官方内部重构只有在能改善本地能力或兼容性时才按边界吸收。
- 版本号用于插件兼容锚定，不用于虚增“已同步提交数”。只有发布兼容契约改变或准备发布版本时才调整版本号。

### 插件兼容判定

当前源码版本为 `4.29.0-beta.1`，与当前官方参考基线的版本标识一致。插件的 `metadata.yaml` 中 `astrbot_version` 使用 PEP 440 范围，由 `astrbot/core/star/star_manager.py` 校验。这个版本范围只是一道声明式兼容门槛，不等于插件 API 已完整兼容；事件、消息组件、Star/Context API、插件页面接口等公开契约仍需按实际变化逐项维护。

每条更新按以下顺序记录：官方来源提交、AG99 本地提交、兼容性影响、验证结果和是否需要重新构建 `data/dist`。仅有文档、品牌或官方 CI 变化，且不影响插件运行时的，标记为 `not_selected`。
